💾 Gestión de Datos

💾 Punto de Restauración

💡 ¿Qué es un Punto de Restauración?
Es una copia de seguridad COMPLETA del sistema que incluye el código HTML, JavaScript, CSS y todos los datos del torneo. Puedes usarlo para restaurar el sistema a este estado exacto en cualquier momento.

📦 Incluye: Sistema completo + Datos + Configuración + Jugadores + Logs

⚠️ Recomendación: Crea un punto de restauración antes de hacer cambios importantes en el sistema o actualizar la aplicación.

🔄 Backups Automáticos

💡 ¿Qué son los Backups Automáticos?
La app guarda automáticamente una copia completa del torneo cada 5 minutos (hasta las 6 más recientes). Sirve de red de seguridad ante errores o cambios no deseados.

🌐 Sincronización Multi-Dispositivo

💡 ¿Qué es la Sincronización?
Compartí el torneo en tiempo real. Un dispositivo edita (host) y los demás lo ven actualizarse al instante. Ideal para proyectar en una TV mientras se edita desde la notebook.
